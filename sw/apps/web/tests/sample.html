Timeless Computing

Zeitlos is a work-in-progress SOC and OS developed in tandem, intended to provide a responsive graphical environment for running timeless applications on FPGA computers. It is the successor to Zucker.

Features

The SOC provides a 32-bit RISC-V CPU (PicoRV32), a line rasteriser and blitter with clipping, and virtual addressing through a Memory Translation Unit. See the repository for details — there’s rather a lot of it.

  • Pre-emptive multitasking
  • Flat memory model with a virtual address space for apps
  • FAT16/32 filesystem, with a zexec loader

Memory Translation Unit

Zeitlos doesn't have an MMU but instead has a single virtual address space that is remapped to a main memory address during context switches.

With the MTU, there is no need for position independent code or complicated address relocation.
