# One to five

```lesson
(objective "Count up to five things.")
(standards "K.CC.B.4")
(minutes 15)
```

We count to find **how many**. Point to each thing once, and say the
next number each time: *one, two, three*.

The last number you say is how many there are.

```figure
(apples 3)
```

---

```check
(choice
  (ask "How many apples?")
  (right "3")
  (wrong "2" "Point to each apple once. Did you miss one?")
  (wrong "4" "Point to each apple only once.")
  (hint "Touch each apple and say a number."))
```
