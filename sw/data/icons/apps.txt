# The dock's icons: one line per icon-<name>.png in this folder.
# gen_dock_icon_data.py turns the two into dock.zic (docs/dock.md).
#
#   name  ["spoken name"]  [needs...]  [hidden]
#
# spoken  what speech says when the dock selection lands on it; the name
#         itself when left out.
# needs   hardware the app cannot do anything without: a Z_FEATURE_* or
#         Z_FEATURE2_* name from sw/common/zsoc.h, lowercase without the
#         prefix (audio, gpio). The dock leaves the icon out on a
#         bitstream that does not have it.
# hidden  @rest does not add it (a row that names it still shows it):
#         casino's tables, which casino starts, and the dock's own icons.
#
# Names starting with @ are the dock's own: @next is icon-next.png,
# @back the BACK icon of an open group, @<id> the icon of the group with
# that id in wm.cfg (@games), and @group the icon of a group with no
# icon of its own. Each is in wm's memory only if its dock shows it.
