# Local networks and IP

```lesson
(objective "Say how frames reach a neighbour on a local network, and how IP addresses and routers carry packets anywhere.")
(minutes 20)
(keywords "Ethernet" "MAC address" "CRC" "network switch" "Wi-Fi" "LoRa" "mesh (network)" "Internet Protocol" "IP" "IP address" "IPv4" "IPv6" "router" "gateway" "DHCP" "DNS" "server (network)")
```

**Ethernet** joins machines on a local network by cable. Each network
interface has its own 48-bit **MAC address**, set at the factory.
Data travels in frames that carry the sender's and the receiver's MAC
addresses and a **CRC** (cyclic redundancy check), a strong kind of
checksum. A **network switch** joins several cables and sends each frame only
out of the socket where its destination is.

**Wi-Fi** does the same by radio. Low-power radios such as **LoRa**
send small messages over many kilometres, slowly. A **mesh** of such
radios, each passing on messages for its neighbours, can link a whole
area with nothing else built.

## IP addresses

The **Internet Protocol** (**IP**) gives every machine on a network an
**IP address**. The original form, **IPv4**, uses 32 bits, written as
four bytes in decimal with dots between, such as `192.168.1.20`. The
newer **IPv6** uses 128 bits: about 3.4 x 10 to the power 38
addresses, enough for every device to have its own.

```sources
(source "Timeless Computing (docs/tc.md), Communication: IP: Addresses and Routing")
```

```check
(choice
  (ask "Which of these can be an IPv4 address?")
  (right "10.0.0.255")
  (wrong "192.168.1.300"
    "Each of the four parts is one byte, 0 to 255. 300 does not fit in a byte.")
  (wrong "192.168.1"
    "An IPv4 address is 32 bits: four bytes, so four numbers.")
  (hint "Four numbers, each one byte."))
```

## Routing

Addresses are grouped in networks. Machines on the same local network
reach each other directly. To reach anything else, a machine sends the
packet to a **router**, its **gateway**, which passes it to another
router nearer the destination, and so on, hop by hop, until it arrives.

No router knows the whole way. Each knows only which way to send
packets for each part of the address space. That is why the Internet
can grow without anyone managing all of it.

```check
(choice
  (ask "A packet goes from your computer to a machine in another country. Which router knows the whole route?")
  (right "None: each router only knows which way to pass it next")
  (wrong "Your gateway"
    "Your gateway knows only where to send the packet next. Each router after it decides the next hop again.")
  (wrong "A central router that manages the Internet"
    "There is none. Routing is done hop by hop, which is why the Internet can grow without one party managing it.")
  (hint "What does each router know?"))
```

## DHCP and DNS

Two services make IP easier to use:

- **DHCP** hands out addresses: a new machine asks the local network
  for one, and a DHCP **server**, a program that answers such
  requests, gives it an address and tells it which
  gateway to use;
- **DNS**, the domain name system, turns names such as `example.org`
  into IP addresses by asking a hierarchy of servers.

```check
(choice
  (ask "You type example.org. Before any packet can go to that machine, what must happen?")
  (right "DNS turns the name into an IP address")
  (wrong "DHCP gives example.org an address"
    "DHCP gives addresses to machines joining your local network. Finding the address that belongs to a name is DNS's job.")
  (wrong "Nothing: routers understand names"
    "Routers pass packets by IP address. The name must first become an address.")
  (hint "Packets carry addresses, not names. Who turns a name into an address?"))
```

---

```check
(number
  (ask "An IPv4 address is 32 bits. How many bytes is it?")
  (answer 4) (from "32 / 8")
  (wrong-if 32 "32 is the number of bits. Each of the four numbers in an address is one byte.")
  (hint "Count the numbers in 192.168.1.20."))
```

So: Ethernet and radio carry frames to neighbours by MAC address, and
IP carries packets anywhere by IP address, router to router.
