# Programming in Scheme

Zeitlos comes with a programming language, Scheme, in the `repl` app.
This course starts with typing your first expression and goes on to
procedures, lists, the procedures that reach files and the rest of the
machine, windows with buttons of your own, and scripts that bring a
slide deck to life.

You need no programming to begin. You should know how to use the
desktop, the dock, windows and files, as the course Getting started
teaches.
