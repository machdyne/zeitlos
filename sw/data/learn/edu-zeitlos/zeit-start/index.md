# Getting started

How to use a Zeitlos computer: what is on the screen, the mouse and the
keys, windows and workspaces, opening apps from the dock, finding and
keeping your files, changing the settings, and getting help with F1.
Each lesson links the page of the Zeitlos documentation it comes from.

You need nothing but this lesson app to begin: if you can go from step
to step here, you are ready. ([Using learn](course:zeit-learn) shows how
lessons work.)
