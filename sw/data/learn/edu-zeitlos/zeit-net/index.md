# The network

How Zeitlos reaches other computers, and how they reach it: reading the
web with `web`, the small internet of Gopher and Gemini, chatting with
`irc`, calling a bulletin board, logging in to another machine with
SSH, and serving your own files ([docs:networking](docs:networking)).

You should already be at home on the desktop: the dock, windows, the
mouse and keys, files and folders, settings and F1 for help (the course
*Getting started*). Every word about networks is explained when it
first comes up.
