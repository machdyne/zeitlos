# C on Zeitlos

C is the language Zeitlos itself is written in. In this course you
write C on the machine, compile it with `zcc`, the compiler that runs
on Zeitlos, and run what it makes: first programs that print, then a
program with a window of its own that answers the keys and the mouse,
programs that read and write files, and programs that send each other
messages.

You should have programmed before, for example through *Programming in
BASIC*: you know what a program, a variable, a loop, an IF and a
subroutine are. You should also know the desktop, the dock, windows,
files and folders, from *Getting started*. Everything about C itself
-- types, functions, pointers, the compiler -- is taught here.
