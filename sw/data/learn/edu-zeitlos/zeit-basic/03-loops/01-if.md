# Decisions with IF

```lesson
(objective "Write a program that does one thing or another, with IF, THEN and ELSE.")
(minutes 20)
(keywords "condition (in a program)" "comparison (in a program)" "true (in BASIC)" "false (in BASIC)")
```

In this lesson your programs start to make choices.

`IF` runs the rest of its line only when a **condition** holds:

```basic
10 INPUT "TEMPERATURE"; T
20 IF T < 0 THEN PRINT "BELOW FREEZING"
30 PRINT "THANK YOU"
```

For -5, line 20 prints `BELOW FREEZING`. For 12, the condition does not
hold, so line 20 does nothing. Either way line 30 runs.

`T < 0` is a **comparison**. BASIC has six:

| Written | Means |
|---|---|
| `=` | equal to |
| `<>` | not equal to |
| `<` | less than |
| `>` | greater than |
| `<=` | less than or equal to |
| `>=` | greater than or equal to |

```check
(choice
  (ask "The program above runs, and you type 0. What does it print?")
  (right "Only THANK YOU")
  (wrong "BELOW FREEZING, then THANK YOU"
    "T < 0 means less than 0. 0 is not less than itself, so line 20 does nothing.")
  (wrong "Nothing"
    "Line 30 is not part of the IF on line 20, so it always runs.")
  (hint "Is 0 less than 0?"))
```

## ELSE

`ELSE` gives the other choice. The part after `THEN` runs when the
condition holds, the part after `ELSE` when it does not:

```basic
10 INPUT "NUMBER"; N
20 IF N MOD 2 = 0 THEN PRINT "EVEN" ELSE PRINT "ODD"
```

An `IF` takes the rest of its line. Everything after `THEN`, up to
`ELSE`, runs when the condition holds, even several statements joined
by colons (`:`). Everything after `ELSE` runs when it does not.

```check
(choice
  (ask "The program above runs, and you type 7. What does it print?")
  (right "ODD")
  (wrong "EVEN"
    "7 MOD 2 is 1, the remainder of 7 divided by 2. 1 = 0 does not hold, so the ELSE part runs.")
  (wrong "EVEN, then ODD"
    "Only one of the two parts runs: THEN when the condition holds, ELSE when it does not.")
  (hint "What is 7 MOD 2?"))
```

## A colon on an IF line

```basic
10 S = 50
20 IF S > 100 THEN PRINT "WELL DONE": S = 0
30 PRINT S
```

```check
(number
  (ask "What does this program print?")
  (answer 50)
  (wrong-if 0 "S = 0 comes after THEN on the same line, so it is part of the IF. S > 100 does not hold, so neither statement runs.")
  (hint "50 > 100 does not hold. Which statements belong to the IF?"))
```

## What a comparison gives

A comparison is a number too. When it holds it is **true**, which BASIC
writes as -1; when it does not, it is **false**, written 0. So
`PRINT 3 > 2` prints `-1`. `IF` runs its `THEN` part for any value
that is not 0.

```sources
(source "Timeless Computing (docs/tc.md), BASIC: Numbers and Arithmetic")
(source "Machdyne BASIC 1 reference (sw/ext/basic/docs/basic1.md), sections 2 and 5")
```

```check
(number
  (ask "What does 10 PRINT 5 = 6 print?")
  (answer 0)
  (wrong-if -1 "-1 is true. 5 = 6 does not hold, so it is false.")
  (wrong-if 11 "= here compares, it does not add: is 5 equal to 6?")
  (hint "Does 5 = 6 hold? False is written 0."))
```

---

```example
(example
  (problem "Write a line that prints PASS for a mark M of 50 or more, and FAIL otherwise.")
  (step "The condition: 50 or more is M >= 50.")
  (step "The line: 20 IF M >= 50 THEN PRINT \"PASS\" ELSE PRINT \"FAIL\"")
  (step (choice (ask "What does it print for a mark of exactly 50?")
    (right "PASS")
    (wrong "FAIL" "M >= 50 means greater than or equal to 50, so 50 passes.")))
  (answer "PASS for 50 or more, FAIL below."))
```

---

```basic
10 INPUT "AGE"; A
20 IF A >= 18 THEN PRINT "ADULT" ELSE PRINT "CHILD"
30 IF A = 18 THEN PRINT "JUST"
```

```check
(choice
  (ask "You run this program and type 18. What does it print?")
  (right "ADULT, then JUST")
  (wrong "Only ADULT"
    "Line 30 is its own IF, and 18 = 18 holds, so it prints JUST as well.")
  (wrong "CHILD, then JUST"
    "18 >= 18 holds, since >= includes equal. So line 20 prints ADULT.")
  (hint "Check each IF on its own: is 18 >= 18? Is 18 = 18?"))
```

So: `IF` runs the rest of its line when its condition holds, `ELSE`
gives the other choice, and a comparison is -1 for true and 0 for
false.
