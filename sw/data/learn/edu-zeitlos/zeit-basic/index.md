# Programming in BASIC

Your first programs, written on the BASIC computer that comes with
Zeitlos ([docs:basic_app](docs:basic_app)): a small home computer in a
window, where you type numbered lines and type `RUN` to see them work.
You learn what a program, a variable and a loop are, and use them to
print, ask questions, draw, animate and, at the end, build a game.

You need no programming at all to begin. You should be able to use the
Zeitlos desktop: open an app from the dock, work with windows and use
the keyboard, as the course *Getting started* teaches.
