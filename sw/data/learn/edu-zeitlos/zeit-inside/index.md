# Inside Zeitlos

How a Zeitlos computer does each of the things a computer must do: the
system on the chip and its address map, the processor and its caches,
main memory and the MTU that gives each program its own view of it, the
graphics hardware, the kernel, the drivers, and what happens from power
on to the desktop. Each lesson links the pages of the Zeitlos
documentation it comes from, and several send you to `info`, `hex` or
the console in `term` to see it on your own machine.

You should already know your way around the desktop
([Getting started](course:zeit-start)) and the general ideas of
[Timeless Computing](course:zeit-tc): bits, bytes and hexadecimal, how
a CPU runs a program from memory, and what an operating system does.
