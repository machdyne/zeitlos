# The gold set.
#
# Hand-written, NOT generated. A model trained on synthetic questions
# and evaluated on synthetic questions will flatter itself; these are
# things somebody would actually type into a machine that is the only
# thing left working.
#
# `hit` is a PROXY for relevance, not a label. A regex over the chunk
# text, because labelling tens of thousands of chunks by hand is not
# going to happen. Good enough to tell rank 1 from rank 22, not good
# enough to tell rank 1 from rank 2 -- do not read these numbers to
# three significant figures.
#
# `src` restricts which datasets can satisfy a question. Use it where a
# question is ABOUT a dataset ("how do I flash a board" is a docs
# question) and leave it off where any source answering correctly is a
# correct answer.
#
# A question matching NOTHING is reported separately by `ask eval` and
# excluded from the totals -- that is a broken question, or one about
# content this pack does not carry, and counting it as a failure would
# make every method look equally worse while hiding the real problem.
#
# Scaled up from twelve because at twelve the run-to-run variation from
# a chunking change was the same size as the effect being measured,
# which makes the harness unable to see the thing it was built to see.

# PARAPHRASE QUESTIONS
#
# The half of the gold set that the first 63 were missing.
#
# 53 of those 63 shared a literal term between the question and the
# pattern defining a correct answer -- which is precisely what BM25
# ranks on, so the metric rewarded term matching by construction and
# lexical retrieval looked unbeatable.
#
# Every question below describes a SITUATION in the words somebody
# would reach for before knowing the technical term, and the `hit`
# pattern deliberately avoids reusing those words. "my hands went white
# and numb" must find the frostbite passage without either of them
# sharing a word.
#
# This is the case dense retrieval exists for. If the trained encoder
# is worth its LUTs it shows up here or nowhere.
# =====================================================================

# =====================================================================
# KEYWORD QUERIES
#
# The third style, and probably the most common one in practice: no
# question, no grammar, two or three words. `ask`'s input box is forty
# columns on a 208-pixel window, which is not a box people write
# sentences into.
#
# Worth testing SEPARATELY from both halves above, because the two
# retrieval halves behave differently here for opposite reasons.
#
# BM25 should be at its best: nothing but content terms, no grammar to
# dilute the idf weighting.
#
# The bow encoder should be at its WORST, and structurally so: a query
# vector is the idf-weighted mean of its term vectors, and averaging
# two or three is a far noisier estimate than averaging the ten or
# twelve a written question supplies. There is no syntax for it to lose
# because there was none, so any advantage it has over BM25 has to come
# from the term vectors alone.
#
# Some are single-concept ("minimum memory"), some deliberately span
# concepts the way a person narrows a search ("jesus bread fish").
# =====================================================================
